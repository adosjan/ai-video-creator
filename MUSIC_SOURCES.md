# Где взять бесплатную музыку для видео

## Бесплатные источники музыки без авторских прав

### 1. YouTube Audio Library (Лучший выбор!)
- **Ссылка:** https://www.youtube.com/audiolibrary
- **Преимущества:**
  - Полностью бесплатно
  - Разрешено для коммерческого использования
  - Не требует указания авторства (большинство треков)
  - Огромный выбор жанров
  - Можно фильтровать по настроению, жанру, длительности

**Как скачать:**
1. Откройте YouTube Studio
2. Перейдите в Audio Library
3. Выберите трек
4. Нажмите кнопку скачивания
5. Сохраните в папку `music/` проекта

### 2. Pixabay Music
- **Ссылка:** https://pixabay.com/music/
- **Преимущества:**
  - Бесплатно для коммерческого использования
  - Не нужна регистрация
  - Хорошее качество
  - Разные жанры

### 3. Incompetech (Kevin MacLeod)
- **Ссылка:** https://incompetech.com/music/
- **Преимущества:**
  - Огромная библиотека
  - Легко искать по настроению
  - Бесплатно с указанием автора
- **Требование:** Указать автора в описании

### 4. Free Music Archive
- **Ссылка:** https://freemusicarchive.org/
- **Преимущества:**
  - Качественная музыка
  - Разные лицензии (проверяйте!)

### 5. Bensound
- **Ссылка:** https://www.bensound.com/
- **Преимущества:**
  - Простой интерфейс
  - Отличное качество
- **Требование:** Указать автора

## Как использовать музыку в системе

### Вариант 1: Через create_full_video.py
```bash
python create_full_video.py
```
Скрипт спросит путь к музыкальному файлу

### Вариант 2: Создать папку music
```bash
mkdir music
```
Сохраняйте всю музыку туда

### Вариант 3: Использовать прямо в коде
```python
create_full_video(
    youtube_url="...",
    background_music_path="music/background.mp3",
    music_volume=0.15  # 15% громкости
)
```

## Советы по выбору музыки

1. **Длительность:** Выбирайте треки длиннее вашего видео (система зациклит автоматически)

2. **Громкость:** Музыка должна быть фоном, не заглушать голос
   - Рекомендуемая громкость: 10-20% (0.1-0.2)

3. **Настроение:** Музыка должна соответствовать теме видео
   - Технологии: электронная музыка
   - История: оркестровая
   - Лайфстайл: поп/инди

4. **Темп:** Для коротких видео (Shorts) выбирайте более динамичную музыку

5. **Без слов:** Используйте инструментальные треки чтобы не отвлекать от голоса
